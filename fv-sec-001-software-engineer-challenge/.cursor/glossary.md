# Glossary

| Thuật ngữ | Ý nghĩa |
|-----------|---------|
| **CTR** | Click-Through Rate — tỷ lệ click trên tổng impressions. CTR = clicks / impressions |
| **CPA** | Cost Per Acquisition — chi phí cho mỗi lần chuyển đổi. CPA = spend / conversions |
| **Impressions** | Số lần quảng cáo được hiển thị cho người dùng |
| **Clicks** | Số lần người dùng click vào quảng cáo |
| **Spend** | Tổng chi phí quảng cáo (đơn vị: USD) |
| **Conversions** | Số lần người dùng thực hiện hành động mong muốn (mua hàng, đăng ký, etc.) sau khi click quảng cáo |
| **Campaign** | Một chiến dịch quảng cáo, định danh bằng campaign_id (format: CMPxxx) |
| **Aggregate** | Gộp/tổng hợp dữ liệu từ nhiều dòng (nhiều ngày) thành một bản ghi cho mỗi campaign |
| **CLI** | Command-Line Interface — ứng dụng chạy qua terminal/command prompt |
| **Streaming** | Đọc file theo từng phần nhỏ thay vì load toàn bộ vào RAM |
| **Chunked processing** | Xử lý dữ liệu theo từng batch/chunk thay vì cả file |
| **Peak memory** | Mức RAM cao nhất mà chương trình sử dụng trong quá trình chạy |
| **Malformed row** | Dòng dữ liệu CSV bị lỗi: thiếu cột, sai format, giá trị không hợp lệ |
| **FV-SEC001** | Mã bài challenge: Flinters Vietnam - Software Engineer Challenge 001 |
